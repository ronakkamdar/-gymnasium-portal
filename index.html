🏛️ Entkoppelte Portal-Architektur

Um die Website sauber erweiterbar zu halten, sind das Portal (Verwaltung & Dashboard) und die Tests (Fachlogik) komplett voneinander getrennt:

gymnasium-hub/
├── index.html              # Hauptportal (Dashboard, Filter, Iframe-Runner)
├── data/
│   └── tests.json          # Alle Metadaten der Tests
├── tests/
│   ├── klasse6/
│   │   ├── ethik-mythen-kant.html     # Unabhängiger Ethik-Test
│   │   └── englisch-unit2-past.html   # Unabhängiger Englisch-Test
│   └── klasse7/
│       └── mathe-geometrie.html

Vorteile dieser Trennung:

  • Kein Konflikt: Jeder Test kann eigene JavaScript-Skripte, CSS und Styles verwenden, ohne das Portal zu beeinflussen.
  • Leichtes Hochladen: Einfach neue HTML-Dateien im Ordner tests/klasseX/ ablegen und über das Formular registrieren.
  • 100% Kostenlos: Funktioniert sofort auf GitHub Pages oder Netlify.
