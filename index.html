🛠️ Wie füge ich neue Tests hinzu?

Das System ist so aufgebaut, dass du ohne Programmierkenntnisse einfach ein neues Test-Objekt in das JavaScript-Array ALL_TESTS eintragen kannst.

Beispiel-Struktur für einen neuen Test:

{
  id: "mathe-kl6-01",
  title: "Bruchrechnen Grundlagen",
  subject: "Mathematik",
  grade: 6,
  description: "Erweitern, Kürzen, ungleichnamige Brüche addieren.",
  cards: [
    {
      id: 1,
      topic: "Bruch erweitern",
      question: "Was bedeutet es, einen Bruch mit der Zahl 3 zu erweitern?",
      answerTitle: "Zähler und Nenner multiplizieren:",
      bullets: [
        "Man multipliziert sowohl den Zähler als auch den Nenner mit 3.",
        "Der Wert des Bruchs ändert sich dabei nicht (z.B. 1/2 = 3/6)."
      ]
    }
  ]
}

Sobald dieser Block im Code eingefügt wird, erscheint der Test automatisch im Dashboard, im Filtermenü und in der Klassenstatistik!

🚀 Wie hoste ich diese Webseite 100% kostenlos?

Da diese gesamte Anwendung als statische Web-App (HTML/CSS/JS) konzipiert ist, benötigst du weder Server noch monatliche Kosten.

Option 1: GitHub Pages (Empfohlen, Dauerhaft kostenlos)
  1. Erstelle ein kostenloses Konto auf github.com.
  2. Erstelle ein neues Repository (z. B. gymnasium-uebung).
  3. Lade diese Datei als index.html hoch.
  4. Gehe auf Settings → Pages und wähle den Branch main.
  5. In unter einer Minute ist deine Seite weltweit unter https://dein-name.github.io/gymnasium-uebung erreichbar!
Option 2: Netlify Drop / Vercel (Per Drag & Drop)

Gehe auf netlify.com/drop, ziehe den Ordner mit dieser Datei hinein und du erhältst sofort eine sichere HTTPS-URL.
